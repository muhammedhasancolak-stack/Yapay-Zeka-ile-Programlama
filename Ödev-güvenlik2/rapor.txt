[KRITIK] Path Traversal (Dizin Atlama)
Kanıt : with open(BASE_DIR + filename, "r", encoding="utf-8") as f:
Neden : Kullanıcıdan alınan 'filename' girdisi, herhangi bir doğrulama, temizleme veya sınırlandırma yapılmadan doğrudan 'BASE_DIR' yolu ile birleştirilmektedir.
Etki  : Saldırganlar '../' karakter dizilimini kullanarak sunucu üzerindeki kök dizine erişebilir, sistemdeki hassas dosyaları (örn. /etc/passwd) okuyabilir veya yetkisiz dosya erişimi elde edebilir.
Öneri (güvenli kod):
    import os
    
    BASE_DIR = "/var/www/uploads/"
    
    def dosya_oku(filename):
        # Dosya adının sadece dosya adı kısmını al ve güvenli yolu oluştur
        safe_filename = os.path.basename(filename)
        filepath = os.path.join(BASE_DIR, safe_filename)
        
        # Dosyanın gerçekten BASE_DIR içinde olduğunu doğrula
        if not os.path.commonpath([BASE_DIR, filepath]) == os.path.abspath(BASE_DIR):
            raise ValueError("Yetkisiz dosya erişim denemesi!")
            
        with open(filepath, "r", encoding="utf-8") as f:
            return f.read()
